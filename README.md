## 🚀 Key Features (from report)
1.  **SOS Emergency** - One-tap alert with live GPS location to security & contacts
2.  **My Location** - Shows current GPS position
3.  **Emergency Contacts** - Add and call with one tap
4.  **Report Incident** - Report with location + photos
5.  **Safety Map** - Security points, safe areas, assembly points
6.  **Emergency Services** & Safe Walk / Check-in

## 🛠️ How it Works
1. Trigger -> 2. Location -> 3. Notify -> 4. Respond -> 5. Support

Built as Android App + Backend services + Database + Security Dashboard + Optional IoT (GPS module & panic button)
